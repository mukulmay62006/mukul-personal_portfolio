# 🌐 Personal Portfolio Website

A simple and responsive **personal portfolio website** created using **HTML5 and CSS3**.  
The website presents my profile, education, technical skills, and contact information in a clean and modern design.

## 👨‍💻 About the Project

This project is a personal portfolio webpage designed to introduce myself as a student and aspiring web developer.

The website includes an attractive hero section with my name, profile image, short introduction, and a "Let's Connect" button.

## ✨ Features

- 👋 Personal introduction
- 🎓 Education section
- 💻 Technical skills section
- 📧 Contact information
- 🖼️ Profile photo
- 🎨 Modern gradient hero section
- 📱 Responsive design for smaller screens
- 🧩 Clean card-based section layout
- 🔗 Navigation to the Contact section

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, colors, spacing, and responsiveness

The project uses HTML5 semantic sections and an external stylesheet named `style1.css`.

The website uses:

- Purple gradient hero background
- Rounded cards
- Circular profile image
